# License Policy

No source texts are included in this scaffold.

Future source records must declare acquisition and license status before ingestion, citation, or
storage. Unknown or restricted sources default to `requires_human_source_review` or
`restricted_do_not_ingest`.

Repository governance documents and schemas may be reviewed for a future project license, but this
scaffold does not grant permission to ingest or redistribute external works.

## Default Source Position

```text
ingestion_allowed: false
citation_allowed: false until reviewed
source_review_required: true
```

## Copyright Boundary

Do not paste copyrighted works, public-domain works, editions, translations, commentary excerpts, or
source corpora into this repo until source review, license review, and ingestion policy are complete.
